Desenvolvemos **sites, sistemas web e painéis administrativos** sob medida para pequenas e médias empresas: do levantamento do que o negócio precisa até a publicação e o suporte depois de no ar.

### O que fazemos
- **Sites institucionais e one page**, rápidos, responsivos e preparados para o Google
- **Sistemas web e painéis administrativos** para o cliente atualizar o próprio conteúdo
- **Sistemas de gestão** (cadastros, contratos, serviços, relatórios)
- **Integrações** com APIs, meios de pagamento e serviços externos
- **Manutenção, correções e evolução** de sistemas existentes

### Como trabalhamos
- Entregas por etapas, testadas e validadas com o cliente
- Segurança desde o início: senhas protegidas, verificação em duas etapas, permissões por perfil
- Acessibilidade e boas práticas em todas as telas
- Documentação de publicação e de uso entregue junto com o projeto

### Tecnologias
- **Back-end:** PHP · .NET (C#) · Python
- **Front-end:** React · Vue · Angular · JavaScript/TypeScript · Bootstrap
- **Bancos de dados:** MySQL · PostgreSQL · SQL Server
